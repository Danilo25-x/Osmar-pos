# Osmar POS

Sistema de punto de venta para tienda, construido como aplicación de escritorio.

## Tecnologías

- JavaScript, React y Vite
- Electron
- Supabase y SQLite

## Requisitos

- Node.js y npm

## Instalación y ejecución

```bash
npm install
npm run dev
```

Para generar una compilación de producción:

```bash
npm run build
```

Para iniciar la aplicación de escritorio:

```bash
npm start
```

Para ejecutar las pruebas:

```bash
npm test
```

## Estructura

- `src/`: interfaz y lógica de la aplicación
- `electron/`: proceso principal de escritorio
- `supabase/`: recursos de Supabase
- `tests/`: pruebas automatizadas
- `docs/`: documentación adicional
